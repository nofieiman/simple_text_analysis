# Sentiment Analysis of Text Reviews

## Overview
This R script performs sentiment analysis on a text file containing product reviews. It processes the text data, visualizes frequent words via a word cloud, analyzes positive/negative word contributions, and calculates overall sentiment scores. The script leverages `tidytext`, `tm`, and `ggplot2` for text mining and visualization.

## Features
- **Text Preprocessing**: Removes punctuation, numbers, and stopwords; converts text to lowercase.
- **Word Cloud**: Visualizes the 100 most frequent words.
- **Sentiment Analysis**: Uses the Bing lexicon to classify words as positive/negative.
- **Sentiment Scores**: Computes overall positive, negative, and net sentiment scores.
- **Visualizations**: Includes bar plots for sentiment contributions and counts.

## Prerequisites
- R (version 4.0 or later)
- R packages: 
  - `tidyverse`
  - `tidytext`
  - `tm`
  - `dplyr`
  - `wordcloud`
  - `ggplot2`
